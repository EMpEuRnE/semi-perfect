วิธีเปิด Move & Earn บน Windows

1. แตกไฟล์ ZIP ทั้งหมดก่อน (Extract All)
2. เปิดโฟลเดอร์ Move-and-earn-first แล้วดับเบิลคลิก START.cmd
3. หาก Windows ขออนุญาตติดตั้ง Node.js ให้กดอนุญาต
4. รอติดตั้ง dependencies จนขึ้น Local: http://localhost:3000
5. เปิด URL ที่แสดงในหน้าต่าง และเปิดหน้าต่างนี้ค้างไว้

ครั้งแรกต้องใช้อินเทอร์เน็ต สคริปต์จะติดตั้ง Node.js LTS ผ่าน winget หากยังไม่มี
จากนั้นใช้ pnpm ตามเวอร์ชันใน package.json โดยไม่ต้องติดตั้ง pnpm เอง
ถ้าเครื่องไม่มี winget สคริปต์จะเปิดเว็บไซต์ Node.js ให้ติดตั้งก่อน แล้วเปิด START.cmd ใหม่
มี .env.local จากโปรเจกต์เดิมแล้ว ไม่ต้องรัน INSTALL_FRESH.sql ซ้ำ

แพ็กเกจนี้ไม่ได้รวม dependencies สำหรับ Windows ไว้ล่วงหน้า
ยังไม่ได้ทดสอบสคริปต์บนเครื่อง Windows จริงหรือยืนยัน flow หลังล็อกอิน
หากพบข้อผิดพลาด ให้ส่งข้อความจากหน้าต่างนี้มา
